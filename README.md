# 🌐 Task 1 - Landing Page

A modern and responsive landing page developed as part of the **Oasis Infobyte Web Development Internship**.

## 📌 About the Project

This project is a visually polished static landing page created using HTML5 and CSS3. The main focus of the project is to demonstrate responsive design, clean layout, navigation, and modern UI styling.

## ✨ Features

- Responsive navigation bar
- Hero section with call-to-action button
- About section
- Services section
- Contact section
- Social media icons
- Responsive design for desktop and mobile
- Clean and modern user interface
- Font Awesome icons through CDN

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome CDN

├── index.html
└── style.css
