# 📝 Task 3 - To-Do Web App

A functional To-Do Web App developed as part of the Oasis Infobyte Web Development Internship.

## 📌 About the Project

This project is a simple and interactive To-Do List Web App created using HTML5, CSS3 and JavaScript.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 Separate Pending and Completed tasks
- 📊 Pending and Completed task counters
- 📱 Responsive design
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
